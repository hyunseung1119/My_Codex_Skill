# Context Reference

Use these rules for long or messy sessions:

- Split work into discovery, implementation, and verification.
- Preserve only high-value state in updates:
  - changed files
  - latest verification command/results
  - active blockers
- If context starts drifting, re-ground on the concrete task and modified files.
- If the task becomes multi-phase, leave a handoff-quality summary in the final response.
